# 🔢 NumPy Data Analytics Project

## 📖 Overview

This project demonstrates the practical use of the NumPy library in Python for numerical and array-based data operations.

The project covers array creation, array properties, reshaping, slicing, mathematical operations, statistical operations, and array stacking using NumPy.

---

## 🛠️ Tools & Technologies

* 🐍 Python
* 🔢 NumPy
* ☁️ Google Colab

---

## 📚 Topics Covered

### 1️⃣ Array Initialization - Single Dimension

Created one-dimensional NumPy arrays using:

```python
a = np.array([7,9,9,2])
```

---

### 2️⃣ Array Initialization - Multi Dimension

Created multi-dimensional NumPy arrays.

```python
b = np.array([(7,9,9,2),(16,11,9,6)])
```

---

### 3️⃣ Generating Arrays

Generated arrays using:

```python
np.arange()
np.linspace()
```

---

### 4️⃣ Array Properties

Explored important array properties:

* 📏 Dimension (`ndim`)
* 💾 Memory Size (`itemsize`)
* 🔤 Data Type (`dtype`)
* 🔢 Total Elements (`size`)
* 📐 Shape (`shape`)

---

### 5️⃣ Array Reshaping

Changed array structure using:

```python
reshape()
```

---

### 6️⃣ Array Slicing

Accessed specific rows, columns, and elements from arrays.
```python

print(b[0,2])
print(b[0:,2])

```

---

### 7️⃣ Array Value Operations

Performed:

* ⬇️ Minimum Value
* ⬆️ Maximum Value
* ➕ Sum of Elements

Using:

```python
min()
max()
sum()
```

---

### 8️⃣ Array Arithmetic Operations

Performed:

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division

Between NumPy arrays.

---

### 9️⃣ Axis-Based Operations

Calculated array sums using:

```python
sum(axis=0)
sum(axis=1)
```

---

### 🔟 Mathematical Functions

Applied mathematical operations:

* √ Square Root
* 📊 Standard Deviation
* 📈 Exponential
* 📉 Natural Logarithm
* 🔟 Log Base 10

Using:

```python
np.sqrt()
np.std()
np.exp()
np.log()
np.log10()
```

---

### 1️⃣1️⃣ Array Stacking

Combined arrays using:

```python
np.vstack()
np.hstack()
```

* 📚 Vertical Stacking
* ↔️ Horizontal Stacking

---

### 1️⃣2️⃣ Array Flattening

Converted multi-dimensional arrays into one-dimensional arrays using:

```python
ravel()
```
